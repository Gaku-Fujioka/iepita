# 効果音設定ガイド 🎵

マッチングモードで使用する効果音を[効果音ラボ](https://soundeffect-lab.info/)からダウンロードして配置してください。

## 📥 ダウンロード手順

### 1. お気に入り（左スワイプ）用の効果音

**推奨音:** 明るい決定音、ポジティブな音

#### おすすめの効果音：
- **「決定ボタンを押す41」** - 明るく軽快な決定音
  - URL: https://soundeffect-lab.info/sound/button/
  - カテゴリ: ボタン・システム音 > 決定、選択
  - ファイル名: `decision41.mp3` → `favorite.mp3` にリネーム

#### ダウンロード方法：
1. [効果音ラボ - ボタン・システム音](https://soundeffect-lab.info/sound/button/)にアクセス
2. 「決定、選択」セクションを見つける
3. 「決定ボタンを押す41」または類似の明るい音を試聴
4. 気に入った音をダウンロード
5. `favorite.mp3` にリネームして `sounds/` フォルダに配置

---

### 2. スター（右スワイプ）用の効果音

**推奨音:** キラキラした特別な音、輝く音

#### おすすめの効果音：
- **「キラキラ音1」** - 軽やかなキラキラ音
  - URL: https://soundeffect-lab.info/sound/anime/
  - カテゴリ: 演出・アニメ > キラキラ、輝き
  - ファイル名: `kirakira1.mp3` → `star.mp3` にリネーム

- **「コインを取る1」** - ゲームっぽい達成音（代替案）
  - URL: https://soundeffect-lab.info/sound/anime/
  - カテゴリ: 演出・アニメ > コイン
  - ファイル名: `coin01.mp3` → `star.mp3` にリネーム

#### ダウンロード方法：
1. [効果音ラボ - 演出・アニメ](https://soundeffect-lab.info/sound/anime/)にアクセス
2. 「キラキラ、輝き」または「コイン」セクションを見つける
3. 「キラキラ音1」または「コインを取る1」を試聴
4. 気に入った音をダウンロード
5. `star.mp3` にリネームして `sounds/` フォルダに配置

---

### 3. 興味なし（上スワイプ）用の効果音

**推奨音:** さっぱりしたキャンセル音、軽い否定音

#### おすすめの効果音：
- **「キャンセル6」** - 軽快なキャンセル音
  - URL: https://soundeffect-lab.info/sound/button/
  - カテゴリ: ボタン・システム音 > キャンセル
  - ファイル名: `cancel6.mp3` → `dislike.mp3` にリネーム

- **「ボタン押下12」** - シンプルなクリック音（代替案）
  - URL: https://soundeffect-lab.info/sound/button/
  - カテゴリ: ボタン・システム音 > ボタン、スイッチ
  - ファイル名: `button12.mp3` → `dislike.mp3` にリネーム

#### ダウンロード方法：
1. [効果音ラボ - ボタン・システム音](https://soundeffect-lab.info/sound/button/)にアクセス
2. 「キャンセル」または「ボタン、スイッチ」セクションを見つける
3. 「キャンセル6」または「ボタン押下12」を試聴
4. 気に入った音をダウンロード
5. `dislike.mp3` にリネームして `sounds/` フォルダに配置

```
  ├── star.mp3      (スター用)
  ├── dislike.mp3   (興味なし用)
  └── README.md     (このファイル)
```

## 🎨 カスタマイズのヒント

お好みに合わせて別の効果音を選んでもOKです！

### 効果音選びのポイント：
- **お気に入り**: 温かみのある、愛情を感じさせる音
- **スター**: 特別感、高級感のある音
- **興味なし**: 不快でない程度の軽い否定音

### 音量調整について：
コード内で音量を調整できます（`index.html` の以下の行）：
```javascript
swipeSounds.favorite.volume = 0.5;  // 0.0〜1.0 で調整
swipeSounds.star.volume = 0.5;      // 0.0〜1.0 で調整
swipeSounds.dislike.volume = 0.4;   // 0.0〜1.0 で調整
```

## ⚡ おまけ: ハプティックフィードバック

効果音に加えて、スマホが振動する「ハプティックフィードバック」も実装済みです！

- **お気に入り**: 30ms の短い振動
- **スター**: 30ms → 50ms → 30ms の特別なパターン
- **興味なし**: 20ms の軽い振動

Android/iPhoneの対応機種で自動的に動作します。

## 🔧 トラブルシューティング

### 効果音が鳴らない場合：
1. ファイル名が正しいか確認（`favorite.mp3`, `star.mp3`, `dislike.mp3`）
2. ファイルが `sounds/` フォルダに配置されているか確認
3. ブラウザのコンソールでエラーメッセージを確認
4. ファイル形式が `.mp3` か確認（`.wav` でもOK）

### ブラウザで音が出ない場合：
- モバイルブラウザは、ユーザーの操作（タップ）がないと音を再生できません
- 最初のスワイプで音が出ない場合は、2回目以降で出るようになります
